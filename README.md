# One month of us ♡

Open `dist/index.html` in your browser. No installation or build needed.

Edit the `postcard` object at the top of `dist/script.js` to change the recipient, sender, and message. Leave a blank line between paragraphs in the message.

The envelope opens into your letter, the shy button runs away a few times, and the happy answer releases a shower of hearts. The layout works on mobile and respects reduced-motion settings.

To serve locally, run:

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory dist
```

Then open http://127.0.0.1:5173.
